# 🐪 Drop-In Dubai

> "Simplifying Travel - One Booking at a Time"

A comprehensive web-based tourism platform designed to simplify travel planning 
and booking for visitors to Dubai. Built as part of the F28WP Web Programming 
coursework at Heriot-Watt University Dubai (Group 14).

---

## 📌 About the Project

Drop-In Dubai is an all-in-one tourist guide web application that allows users 
to discover, explore, and book hotels, restaurants, attractions, and events 
across Dubai. The platform includes personalised user profiles, a favourites 
system, real-time booking management, and a secure admin dashboard for 
managing listings and content.

The goal was to design and build a fully functional, database-driven web 
application using modern web technologies, following a three-tier 
client-server architecture.

---

## ✨ Key Features

- Browse and book hotels, restaurants, attractions, and events
- User authentication with role-based access (Admin & Customer)
- Personalised profiles with booking history and favourites
- Real-time booking management (create, modify, cancel)
- Admin dashboard for content and listing management
- Responsive design across mobile and desktop

---

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript, jQuery, AJAX

**Backend:** Node.js, Express.js

**Database:** MySQL (via XAMPP & phpMyAdmin)

**Security:** BCrypt password hashing, CORS middleware

**Other:** REST API, JSON, Git & GitHub
